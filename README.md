# NOVA

NOVA is a personal virtual assistant that runs on your own hardware. She lives on your machine, works with your files and tools, and helps you get things done.

**Version:** 1.0.0

## What NOVA is
- A personal AI assistant running locally, not a cloud service.
- A tool for building, researching, and organizing — code, notes, reminders, and projects.
- An information filter that summarizes what matters and hides the noise.

## What NOVA can do
- Research — search the web, read pages, and pull news and weather.
- Write and build — create projects, write code and documents, and run scripts.
- Manage time — set reminders and timers, and run recurring routines.
- Remember — keep lasting facts and preferences so context carries across conversations.
- Work in the background — take on longer tasks and report back when they finish.

## What NOVA does not do
- Send email or messages, read a calendar, make bookings, or buy things.
- Control smart-home devices or see cameras.
- Access files outside the folders you have allowed.

NOVA is built to be useful, private, and on your side.
